# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/BahodirMadatov/tmdb-movies-sdk/security/advisories/new.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/BahodirMadatov/tmdb-movies-sdk/issues

## Scope

This policy applies to the generated Bahodir Madatov SDK packages published from this
repository (npm).

This is an unofficial SDK for the TMDB public API, generated by
Bahodir Madatov. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
